# Mateus Monteiro – Portfolio Web  
Este repositório contém os arquivos do meu site pessoal desenvolvido para apresentar meus trabalhos, habilidades e contato.

## 🔍 Visão Geral  
- Projeto: **Portfolio Web**  
- Autor: Mateus Monteiro  
- Tecnologias principais: HTML, CSS, JavaScript  
  - HTML para a estrutura de páginas  
  - CSS para layout, responsividade e estilo  
  - JavaScript para interatividade (ex.: digitação automática)            

## 🎯 Funcionalidades  
- Layout responsivo: adaptável para desktop, tablet e celular.  
- Seção “Sobre mim”: pequena introdução com foto e descrição profissional.  
- Seção “Projetos”: mostra os trabalhos que desenvolvi com links ou screenshots.  
- Seção “Contato”: formas de me encontrar (e‑mail, LinkedIn etc).  
- Efeito de digitação automática para destacar títulos ou frases‑chave (via `typing.js`).  
- Design limpo e navegabilidade simples.

## 📦 Tecnologias & Ferramentas  
- HTML5  
- CSS3 (Flexbox, media queries)  
- JavaScript ES6+  
- Editor: Visual Studio Code (ou similar)  
- Hospedagem: GitHub Pages (ou outro serviço estático)  
- Controle de versão: Git & GitHub
